## Theorem blocks

### thm-a4-1: LP reduction of the optimal guaranteeing program (shrunk terminal set)
- statement: For model (1.1) `x(t+1) = Ax(t) + Bu(t) + Mw(t)`, `x(0) = x_0`,
  `u(t) ∈ U = {u : u_min ≤ u(t) ≤ u_max}` (componentwise box), `w(t) ∈ W = {w :
  ‖w‖_∞ ≤ w_max}`, polyhedral terminal set `X_T = {x : g_min ≤ Hx ≤ g_max}`, and
  worst-case linear criterion (1.3) `max_w c^⊤x(T|x_0,u,w)`: define the
  estimate vector `γ_i = w_max Σ_{t=0}^{T−1} |h_i^⊤ A^t M|_1` (and
  `γ_0 = w_max Σ_t |c^⊤ A^t M|_1`). If the nominal (disturbance-free) optimal
  control steers `x_0` into the shrunk set `X̄_T = {x : g_min + γ ≤ Hx ≤ g_max − γ}`,
  then (1.2) is guaranteed; the optimal guaranteeing program is the solution of
  LP (1.5) `min_u Σ_t c^⊤ A^{T−t−1} B u(t)` with the shrunk constraints, and its
  value is `J(x_0)` from LP (1.4) `min_u c^⊤x_0(T) + γ_0`.
- conditions: linear stationary discrete system; polyhedral `U`, `W`, `X_T`;
  finite horizon `T`. If `X̄_T = ∅`, no guaranteeing program exists.
- anchor: A4_Дмитрук_2022.pdf, p. 3 (journal p. 68) — «Вектор оценок γ = (γ_i,
  i = 1, …, m) позволяет задать "суженное" терминальное множество X̄_T = {x ∈ R^n :
  g_min + γ ≤ Hx ≤ g_max − γ}.»
- our-relevance: this is the k = 0 rung of our ladder (pure program, OC): for
  our bridge class (A = I, B = (1,1)^⊤) the γ-vector has an explicit closed form
  and `J(x_0)` is the baseline `V(∅)` against which every schedule `R` must improve.

### thm-a4-2: DP characterization of the optimal multiply-closed strategy; program-vs-strategy inequality
- statement: With closure moments `T_1 < … < T_N` fixed in advance and segments
  `Δ_j = {T_j, T_j+1, …, T_{j+1}−1}` (`T_0 = 0`, `T_{N+1} = T`), define
  `V_N(x_N) = min_{u_N} max_{w_N} c^⊤x(T|x_N,u_N,w_N)`, `X(T|x_N,u_N) ⊆ X_T` (2.7)
  and the backward recursion `V_j(x_j) = min_{u_j} max_{w_j} V_{j+1}(x(T_{j+1}|x_j,
  u_j,w_j))`, `j = N−1, …, 0` (2.8) — called in the text the analogue of the
  Bellman equation. Then the optimal strategy `π^0_N(0,x_0)` consists of the
  initial program solving (2.8) at `j = 0` plus nested optimal strategies on the
  remaining closures (2.1)–(2.3); its guaranteed quality is
  `V_0(x_0) = min_{u_0} max_{w_0} … min_{u_N} max_{w_N} c^⊤x(T)`, while the
  program value is `J(x_0) = min_{u_0} max_{w_0} … max_{w_N} c^⊤x(T)`, and by the
  minimax inequality `V_0(x_0) ≤ J(x_0)`.
- conditions: Assumption 1 (state can be measured and control re-chosen at each
  `T_j`); Assumption 2 (all closing sets `X_1, …, X_N` nonempty); admissibility
  (2.6): `X(T_1|x_0,u_0) ⊆ X_1`.
- anchor: A4_Дмитрук_2022.pdf, p. 6 (journal p. 72) — «Принимая во внимание
  неравенство минимаксов, можно заключить, что V_0(x_0) ≤ J(x_0).»
  (recursion (2.8) and «находятся из аналога уравнения Беллмана»: p. 5, journal p. 71)
- our-relevance: this is precisely the middle of our ladder OC → RO(k) → DP:
  A4 constructs the optimal RO(N) strategy for a GIVEN schedule and proves only
  the two-rung inequality program ≥ RO(N); no monotonicity in the schedule
  (insertion/refinement of closures) is claimed anywhere in the paper.

### thm-a4-3: Closing sets are polyhedral; value function piecewise-linear convex
- statement: The level sets `X_j(α) = {x ∈ X_j : V_j(x) ≤ α}` (2.9) are convex
  polyhedra; `V_j(x_j)` is a piecewise-linear convex function (as the optimal
  value of an LP), hence for each fixed `α` its Lebesgue set `X_j(α)` is a convex
  polyhedron (possibly unbounded); moreover `X_j(α_min) ⊆ X_j(ᾱ) ⊆ X_j` for
  `α_min ≤ ᾱ ≤ α_max`, while `X_j(α_max)` and `X_j` need not coincide. Terminal
  level set for `j = N`: `X_{N+1}(α) = {x : g_min ≤ Hx ≤ g_max, c^⊤x ≤ α}`.
- conditions: LP reducibility of (2.7)/(2.8), which holds recursively for the
  linear-polyhedral profile of A4; `α ∈ [α_min, α_max]` with `X_j(α) ≠ ∅`
  (`α_max = J(x_0)` when a guaranteeing program exists).
- anchor: A4_Дмитрук_2022.pdf, p. 7 (journal p. 72) — «Заметим, что все X_j(α)
  являются выпуклыми многогранниками.» (inclusion chain: p. 7–8, journal p. 72–73 —
  «Очевидно, X_j(α_min) ⊆ X_j(ᾱ) ⊆ X_j, при этом множества замыкания X_j(α_max) и
  X_j в общем случае могут не совпадать.»)
- our-relevance: for our ‖x_T‖₁ cost the terminal level polytope is the ℓ₁-ball
  `{x : ‖x‖₁ ≤ α}`, so A4's entire level-set pipeline transfers verbatim — this
  gives the geometric language (level sets as "wedges") for our wedge/plateau analysis.

### thm-a4-4: Утверждение 1 (Statement 1) — parametric halfspace representation of approximating closing sets
- statement: For the outer approximations `X̄_j(α) = {x : p_{ji}^⊤x ≤ f_{ji}(α),
  i = 1,…,m_j}` (2.12), where `f_{ji}(α) = max_{x∈X_j(α)} p_{ji}^⊤x` (2.11) are
  support functions along normals `p_{ji}` chosen independently of `α`, there
  holds the representation `X̄_j(α) = {x ∈ R^n : P_j x ≤ g_j + λ_j α}`,
  `α ∈ [α_min, α_max]` (2.13), where the block matrices/vectors (2.18)–(2.19) are
  built from `P_{ji} = (p_{ji}; k = 1,…,K_{ji})`, `g_{ji} = (f^k_{ji} − λ_{j+1}^⊤
  y^k_{ji} α^k_{ji}; k = 1,…,K_{ji})`, `λ_{ji} = (λ_{j+1}^⊤ y^k_{ji}; k = 1,…,K_{ji})`,
  each normal repeated `K_{ji}` times.
- conditions: induction on `j = N, N−1, …, 1`, replacing `X_{j+1}` by its
  approximation and freezing the disturbance worst-case contributions
  `χ_{ji} = w_max Σ_{t∈Δ_j} ‖p_{j+1,i}^⊤ A^{T_{j+1}−t−1} M‖_1`; Assumption 3
  (`X_j(α_max)` all nonempty) for the suboptimal regime.
- anchor: A4_Дмитрук_2022.pdf, p. 11 (journal p. 76) — «Утверждение 1. Для
  аппроксимации (2.12) имеем место представление (2.13), где P_j, g_j, λ_j,
  вычисляются по правилам (2.18), (2.19).»
- our-relevance: the affine-in-α right-hand sides with `λ_j ≥ 0` are the
  structural fact our analytic proofs need: values and reachable-set constraints
  depend on the information parameter affinely piecewise — the exact mechanism a
  plateau result for the schedule parameter would be built on.

### thm-a4-5: Piecewise-linear support values via parametric LP duality + basis-tracing algorithm
- statement: Each support value `f_{ji}(α)` equals the value of parametric LP
  (2.14) (scalar parameter `α` enters only the right-hand side, linearly), whose
  dual reduces to `f_{ji}(α) = min_y (g_{j+1} + λ_{j+1}α − χ_j)^⊤ y + e_{ji}`,
  `G_j^⊤ y = p_{ji}`, `y ≥ 0` (2.16). Hence `f_{ji}` is piecewise-linear convex
  on `[α_min, α_max]`, and an explicit algorithm (basis-sensitivity analysis of
  (2.14)/(2.16)) yields `K_{ji}` breakpoints `α^1_{ji} = α_max > α^2_{ji} > … >
  α^{K_{ji}}_{ji} > α^{K_{ji}+1}_{ji} = α_min` and dual solutions `y^k_{ji}`
  constant on each `[α^{k+1}_{ji}, α^k_{ji}]`, giving the exact representation
  `f_{ji}(α) = min_{k=1,…,K_{ji}} {f^k_{ji} + λ_{j+1}^⊤ y^k_{ji}(α − α^k_{ji})}` (2.17).
  Degenerate cases are handled: dual unbounded below ⇒ correct `α_min`;
  dual infeasible ⇒ the direction `p_{ji}` is redundant and is deleted (this is
  what happens when `X_T` is unbounded); a small `ε > 0` guards against kink
  degeneracy.
- conditions: LP (2.14) solvable for the current `α`; the three standard
  postoptimal situations (solved / unbounded / infeasible) recognized and routed.
- anchor: A4_Дмитрук_2022.pdf, p. 10 (journal p. 75) — «В результате работы
  приведенного алгоритма будет найдено число K_ji и последовательность
  α^1_ji = α_max > α^2_ji > … > α^{K_ji} > α^{K_ji+1} = α_min, а также двойственное
  решение y^k_ji задачи (2.16), которое остается постоянным на каждом промежутке
  [α^{k+1}_ji, α^k_ji] значений параметра.»
- our-relevance: this is the analytic machinery our scheduling law currently
  lacks: LP duality produces verifiable certificates (dual vectors) and exact
  piecewise-affine dependence of values on a scalar parameter — the natural tool
  to certify plateau intervals, provided we can set `V` up as a parametric LP in
  schedule-dependent data.

### thm-a4-6: One-shot LP for the suboptimal initial program
- statement: Replacing `X_1(α)` in the `j = 0` problem (2.10) by its
  approximation of the form (2.13) collapses the construction of the suboptimal
  initial program to a single LP (2.20) in variables `(u_0(·), α)`:
  `V_0(x_0) = min α` s.t. `Σ_{t∈Δ_0} P_1 A^{T_1−t−1} B u_0(t) − λ_1 α ≤ g_1 −
  χ_0 − P_1 A^{T_1} x_0`, `u_min ≤ u_0(t) ≤ u_max`, `α ≥ α_min`. It has
  `rT_1 + 1` variables and `m̄_1` main constraints; it is solved once and returns
  simultaneously the value estimate `α^0 = V_0(x_0)` and the program `ũ^0_0(·|x_0)`
  — unlike [9], where the approximation problems (2.11) and an LP comparable to
  (2.20) are solved repeatedly for fixed `α`. After the measurement at `T_1`,
  only LPs of type (2.20) are re-solved in real time.
- conditions: approximations of all closing sets built once, offline (Assumption
  3 regime); with outer approximation the realized terminal state may miss the
  exact closing set (two situations distinguished: suboptimality gap `α^* − α^0`,
  or a disturbance `w^*(·)` driving `x^*(T_j) ∉ X_j` — continuation impossible).
- anchor: A4_Дмитрук_2022.pdf, p. 12 (journal p. 77) — «…задача (2.20) решается
  только один раз и сразу дает оптимальное значение параметра α^0 = V_0(x_0) и
  субоптимальную начальную программу ũ^0_0(·|x_0).» (size: p. 11, journal p. 76 —
  «Результирующая задача линейного программирования вида (2.20) имеет rT_1 + 1
  переменную и m̄_1 основных ограничений.»)
- our-relevance: an explicit complexity account of the RO(k) rung (variables grow
  with the length of the first segment only), and a template for how our judges
  could certify a strategy by one LP plus a posteriori gap.

## Fact blocks

### fact-a4-1: The closure schedule is assumed FIXED a priori; it is never optimized
- statement: The moments `T_1 < … < T_N` are fixed before the control process
  starts; all constructions (closing sets, strategies, LPs) are for that given
  schedule. Different schedules are compared only numerically, by recomputing
  `V_0` for a grid of `T_1` values and a few ad hoc multi-closure schedules.
  There is no algorithm, no optimality condition, and no structural theorem for
  choosing the schedule, and Assumption 1 ties measurement/correction to exactly
  those pre-fixed moments (no adaptivity of the schedule itself).
- anchor: A4_Дмитрук_2022.pdf, p. 4 (journal p. 69) — «Пусть до начала процесса
  управления зафиксированы моменты T_1 < T_2 < … < T_N, T_j ∈ {1, 2, …, T − 1};
  j = 1, 2, …, N. Согласно работам [9; 14] будем называть их моментами замыкания
  оптимизируемой системы (1.1).»
- our-relevance: collision check passed — our scheduling law (when to close,
  plateau filling) does not overlap any A4 result; A4 supplies the value oracle
  `V(R)` for fixed `R`, which our law can consume.

### fact-a4-2: Example 1 gives quantitative ladder data (one-channel matched uncertainty)
- statement: Example 1 (journal pp. 77–79): 2-dim damped-rotation system
  `A = [[0.9950, 0.0998], [−0.0998, 0.9950]]`, control and disturbance enter
  through the SAME channel `B = M = (0.0050, 0.0098)^⊤`, `x(0) = (0,1)^⊤`,
  `T = 120`, `|u| ≤ 1`, `|w| ≤ 0.5`, criterion `x_2(T) → max`, terminal strip
  `X_T = {2 ≤ x_1 ≤ 10}` (`x_* = 2`, `x^* = 10`). Values: program `J(x_0) =
  1.501102`; one closure: `V_0 = 1.935795 (T_1=10), 2.578177 (40), 2.687073 (50),
  2.633505 (60), 2.835391 (70), 2.754215 (80), 2.735537 (90), 1.681654 (100)`;
  `V_0 = J` for `T_1 ≥ 104`; two closures (40, 80): `V_0 = 3.182802`; five
  closures (20, 40, 60, 80, 100): `V_0 = 3.347376`. «Задача (3.1) имеет решение
  в классе гарантирующих программ … гарантированное значение J(x_0) = 1.501102.»
  (p. 12); «При T_1 ≥ 104 оптимальная стратегия не дает улучшения критерия
  качества оптимальной гарантирующей программы, т.е. V_0(x_0) = 1.501102.» (p. 12).
- anchor: A4_Дмитрук_2022.pdf, p. 12–14 (journal pp. 77–79).
- our-relevance: numerically realized ladder OC(1.501) → RO(1)(≤2.913) → RO(2)
  (3.183) → RO(5)(3.347) for a matched-uncertainty system; the full-feedback
  (DP) endpoint is not computed — our DP rung would complete their table.

### fact-a4-3: V as a function of the single closure moment is NON-monotone with an interior peak
- statement: «Функция V(x_0) = V(x_0|T_1) как функция момента замыкания достигает
  максимального значения (задача (3.1) — на максимум) при T_1 = 67, и это значение
  равно 2.913110.» The curve rises from 1.936 at `T_1 = 10` to the peak 2.913 at
  `T_1 = 67` (≈ 0.56 of the horizon), with local non-unimodal wiggles on the grid
  (dip at 60), then collapses to 1.682 at `T_1 = 100` and to the program value at
  `T_1 ≥ 104`.
- anchor: A4_Дмитрук_2022.pdf, p. 13 (journal p. 78).
- our-relevance: direct published evidence for our wedge/plateau phenomenology —
  the value of information concentrates in an interior window of the schedule and
  vanishes near both ends; our scheduling law must reproduce this peak on their
  instance as a validation target.

### fact-a4-4: Existence separation: the strategy may exist where the program does not
- statement: For `x_* = 2`, `x^* = 7` (denser strip) the optimal guaranteeing
  program does not exist (mirroring the continuous example of [9]), yet the
  optimal one-closure strategy exists: «Однако оптимальная стратегия π^0_1(0, x_0)
  существует и совпадает с решением для задачи c x^* = 10, что, очевидно, следует
  из неактивности ограничения x_1(T) ≤ 10.» (journal p. 78). Complementary
  robustification: if closing sets are empty, solve for the inflated ball
  `w_ε = {w : ‖w‖ ≤ w_max + ε}` with small `ε > 0` so that the perturbed
  approximation covers the original closing sets (journal p. 77).
- anchor: A4_Дмитрук_2022.pdf, p. 13 (journal p. 78); ε-trick: p. 12 (journal p. 77).
- our-relevance: information strictly enlarges the feasible domain, not only the
  value — supports treating our scheduling law as choosing among genuinely
  different feasible strategy classes, and gives a fallback when our bridge class
  is infeasible at a given `R`.

### fact-a4-5: Computational profile: offline approximation dominates, online is one cheap LP
- statement: Example 1: 203 normals for `X_1(α)` (200 unit vectors
  `(cos φ, sin φ)` + 3 terminal-related rows); since `X_T` is unbounded, 100
  directions were deleted at step 3.3 of the algorithm, leaving `m̄_1 = m_1 = 103`
  main constraints; average LP (2.20) time 0.016 s once approximations are built;
  building them ≤ 4.5 s. Five closures: LP (2.20) 0.02 s, approximations 36 s
  («Время решения задачи (2.20) составило 0.02 с, время построения аппроксимаций
  множеств замыкания — 36 с.», journal p. 79). Example 2: 75 normals with one
  kink, 75 with another, `m̄_2 = 355`, `m̄_1 = 605`, LP time 0.027 s. «Отметим,
  что наиболее трудоемкая операция проходит на решении задач (2.16) и построении
  аппроксимирующих множеств замыкания, однако она выполняется однократно до начала
  процесса управления.» (journal p. 80).
- anchor: A4_Дмитрук_2022.pdf, p. 12, 14, 15 (journal pp. 77, 79, 80).
- our-relevance: the expensive certificate is offline and computed once — the
  same economics our judges/gates assume; per-schedule re-evaluation is cheap
  once the α-parametric set representations exist.

### fact-a4-6: Accuracy is certified only a posteriori, per example
- statement: With exact closing sets one would have `c^⊤x^*(T) = V_0(x_0) = α^0`;
  «В силу аппроксимации, однако, V_0(x_0) − c^⊤x^*(T) ≥ 0, и эта величина позволяет
  оценить точность аппроксимации и субоптимальности построенной начальной программы
  ũ^0_0(·|x_0).» (journal p. 78). Realized accuracies: 4.7·10⁻⁴ (Ex. 1, one
  closure at 67), 1.6·10⁻³ (two closures), 6·10⁻⁴ (five closures), 4.7·10⁻³
  (Ex. 2). No a priori error bound for the normal grid is given: justification
  «насколько точно может быть предложена аппроксимация, будет представлено в
  разд. 3 для конкретных примеров» (journal p. 73).
- anchor: A4_Дмитрук_2022.pdf, p. 8, 13, 14 (journal pp. 73, 78, 79).
- our-relevance: even in this school the approximation error has no a priori
  theory — an analytic certification of our scheduling law (or of level-set
  approximations) would be a genuine addition, not a re-derivation.

## Landscape

- relates to our lines:
  - Scheduling law — A4 fixes `R` a priori and optimizes only the strategy within
    the fixed-`R` class (fact-a4-1, Assumption 1). No collision: our contribution
    (when to close; plateau filling the domain) lives in a class A4 does not
    enter. A4's Example-1 table `V(x_0|T_1)` is however a mandatory consistency
    target for our value oracle.
  - Maxmin value — their `V_0(x_0)` for given `R` is exactly our `RO(|R|)(x_0; R)`;
    constructed exactly in-class given exact closing sets, suboptimal with
    a posteriori gap under polyhedral outer approximation (thm-a4-6, fact-a4-6).
  - Wedge — fact-a4-3 is a one-dimensional slice of our landscape: interior peak
    at ≈ 0.56·T, decay to zero gain near both ends, non-unimodal wiggle; A4 has
    no theory of this shape (pure numerics on one example).
  - Ladder monotonicity — only the two-rung inequality `V_0(x_0) ≤ J(x_0)` is
    proven (thm-a4-2); monotonicity under inserting/refining closures is neither
    stated nor proven; numerics (fact-a4-2) are consistent with monotone
    improvement but the multi-closure schedules chosen are nested-ish
    (20/40/60/80/100), not adversarial.
  - Duality machinery — the entire proof load is LP duality + parametric-LP
    basis sensitivity + polyhedral outer approximation + backward recursion
    (thm-a4-4, thm-a4-5); no Pontryagin maximum principle, no KKT of nonlinear
    programming, no measure-theoretic duality. The α-parametric representation
    `P_j x ≤ g_j + λ_j α` (thm-a4-4) is the closest existing relative of our
    plateau claim, with α playing the role of the information-level parameter.
  - Model match — (1.1) is a strict superset of our bridge class except: (a) A4's
    `W` is an L∞ ball while our `w ∈ {−1,+1}` (convexification is value-preserving
    by affinity in `w` for linear terminal cost — needs a one-line lemma on our
    side); (b) A4's cost is linear `c^⊤x(T)` while ours is `‖x_T‖₁` — but the
    level-set reformulation (2.10) only needs the terminal level polytope, and
    `{x : ‖x‖₁ ≤ α}` is an ℓ₁-ball polytope, so the pipeline transfers; (c) A4
    allows an unbounded `X_T` (strip in Ex. 1), matching our unconstrained
    terminal state.

## Open threads for our portfolio

1. Ladder monotonicity theorem: prove `RO` monotone under schedule refinement for
   the bridge class. A4 proves only 0-closures vs N-closures (`V_0 ≤ J`); the
   intermediate rungs are unclaimed territory even in this school.
2. Closed-form `V(R)` for the bridge class: A4 computes values only by solving
   LPs; no formula even in the examples. Our plateau/wedge formulas would be new
   relative to the whole line [7–14].
3. Parametric-LP route to analytic certification of the scheduling law: A4's
   basis sensitivity gives piecewise-affine dependence of values on a continuous
   RHS parameter (α). If we formulate `V` as an LP whose data depend on the
   schedule `R`, the same technique yields constancy (plateau) intervals — but
   `T_j` are integers, so either relax or exploit plateau structure; this is
   precisely where our analytic certification could be built.
4. Adaptive schedules (decide whether to close based on the measurement) are
   outside A4's class by construction (Assumption 1); our thesis must state
   explicitly which strategy class the scheduling law optimizes over.
5. Transfer lemmas to write on our side: convexification of `w ∈ {−1,+1}` to the
   L∞ ball; ‖·‖₁ cost via terminal ℓ₁-ball level sets; explicit γ-vector for

## Verdict for our reading queue

Deep-read complete; A4 is the anchor paper for the RO(k) definition and the
multiclosure construction in the Dmitruk (Minsk) LP line, and the closest
neighbor to our bridge class (matched-uncertainty example included). It does NOT
optimize or adapt the closure schedule — schedules are frozen a priori and
compared only numerically — so our scheduling-law contribution stands clear of
it, with their Example-1 value table as a validation obligation. Its machinery
(LP duality, parametric-LP basis sensitivity, polyhedral level sets, backward
minimax recursion) is exactly the analytic route our currently only
numerically-certified scheduling law needs; the notable gaps it leaves us: no
refinement-monotonicity theorem, no closed-form `V(R)`, no a priori approximation
bounds, no full-feedback endpoint. Keep at top priority; pair with A2/A5 reads.
