- **Dictionary and expansion:** `correspondence.md:11-41` consistently separates first-stage program a, measured state s, suffix block b, prefix disturbance image and unobserved future disturbances. - **Both witness directions:** `:45-57` uses `y(xi)=pi(s0(a)+xi)` and `pi(s)=y(s−s0(a))`. For fixed a these are translations of the same closed observation domain, preserve Borel measurability, and give the same physical controls and complete trajectories for each disturbance path. Off-domain extension is not claimed feasible; the saved interface rejects unreachable states.
- **First-stage dependence:** `:51-55` uses the exogenous deviation `xi=Lw−` in `Z=L(W^r)`, independent of a. The known first-stage decision supplies the state translation. The translated state set is not silently declared exogenous.
- **Information fibres:** `:59-63` explicitly requires equal suffix blocks on equal observations for a path-indexed rule. Removing this requirement only for feasibility/value is justified here because `K(xi)` depends on the path through xi alone. Finite vertex selection/interpolation supplies a Borel replacement; an arbitrary path policy is not claimed trajectory-equivalent or automatically quotient-measurable.
- **Quantifiers and rectangularity:** `:45-55,65-79` keeps `exists a,pi,eta; forall w−; forall w+` with the suffix fixed by the one state measurement. The reduced feasibility test is `forall xi exists b forall w+`, never `forall xi forall w+ exists b`. Every prefix admits the same future box. Temporal Cartesian-product independence is not confused with BT04 constraint-wise independence.
- **Supports and signed objective:** `:65-79` tightens each terminal row separately, with `R=[H;−H]`, and includes the separate row `c^T z−eta<=−kappa(c)`. Independent row maximizers need not coincide. c is not replaced by its absolute value. Maximized reward corresponds to `c=−e2`, `eta=−q`, and `[L,U]` maps to `[−U,−L]`.
- **Feasibility and infeasibility:** `:28,49,83,93` does not assume complete recourse. Missing suffixes make the vertex LP infeasible. Empty feasible policy class has value `+infinity`; compact controls preclude `−infinity` in a feasible class. Finite-LP attainment is a written consequence, not a solver observation or a zero-gap claim.
- **Real-state extension and degeneracy:** `:83-93` evaluates actual observed-image vertices for necessity and uses fixed relative-hull triangulation, unique simplex barycentric coordinates and a finite boundary rule for sufficiency. Convex controls and fixed recourse preserve every tightened row. The argument handles rank deficiency without inverse dynamics. Disturbance-box vertices may map to duplicate/interior state images and are not identified with state-image vertices. Terminal image Q=PZ is separately justified by identical feasible suffix sets.
- **Methods and closure sets:** `methods-and-boundaries.md:7-35` separates complete exact FME/duality/vertex methods from affine restrictions and incomplete scenarios. `correspondence.md:97-103` compares representations of the same cost-level feasibility set. Outer containment is only a relaxation (lower cost/upper reward), while a witness-bearing inner restriction gives the opposite feasible bound.
