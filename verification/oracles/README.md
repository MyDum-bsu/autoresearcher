# `verification/oracles/` — Точные рациональные оракулы (R2 `#1156`)

- `exact_lp.py` — чистый точный рациональный (`fractions.Fraction`) двухфазный симплекс-метод по правилу Блэнда без чисел с плавающей точкой, с независимой проверкой прямой допустимости и значения целевой функции.
- `m0/` — точный конечный эталон `finite_reference.py`, независимый Беллман по ячейкам состояний `finite_bellman.py` и сертификатор открытого контура `a4_certificate.py` / `a4_check.py` (36 тестов в `-B` и `-O`).
- `wave4-a4-closures/` — точные рациональные сертификаты переноса ОГУ → ARO для модели `A4` (`r = 67, 104`, 32 контроля).
