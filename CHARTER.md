## 1. Научный фокус (Q1)

- **Основная линия магистерской работы:** мост **оптимальное гарантированное управление (ОГУ, школа Дмитрук A1–A5) ↔ двухэтапная адаптивная робастная оптимизация (ARO) с фиксированным рекурсом**, ценность информации и выбор расписания моментов замыкания `R` (`O4 + O7`).
- **Прикладная ветвь внутри моста:** условия точности аффинных решающих правил (`ADR/LDR`, `O1/O2/O5`) с обязательной батареей фальсификации `T1–T7`.

## 2. Железные правила научной истинности

1. **Внешняя опора обязательна.** Любая ссылка на литературу = физическая страница PDF + SHA-256 из `corpus/MANIFEST.md` (или `corpus/extra/`). Цитирование по памяти запрещено.
2. **LLM не судит истинность.** Вердикты выдают только детерминированный код (`verification/oracles/`, `verification/falsifiers/`, `verification/gates/`) и ядро **Lean 4**.
3. **Falsify-First (Q3, Ярус 1).** Ни одна гипотеза не допускается к доказательству/формализации, пока не пережила точный рациональный LP / Беллман / SymPy и батарею `T1–T7` (с запретом пустых сеток и проверкой в `-B` и `-O`). Опровержение — полноценный артефакт в `research/counterexamples/`; опровергнутый родитель никогда не перезаписывается.
4. **Двойной замок ядра (Q3, Ярус 2).** Для **2–4 главных несущих теорем** диссертации обязательно доказательство в **Lean 4**: замороженная формулировка (`Goals.lean` не меняется автором при сдаче), `lake build` = 0 ошибок / 0 `sorry`, positive allowlist аксиом строго `⊆ {propext, Classical.choice, Quot.sound}`, позитивные и негативные контроли `C1–C6`, плюс независимое ревью **Semantic Fidelity** (`board-review.mjs`, Pi `openai/gpt-6.2-sol`).
5. **No Black-Box Theorems (Q5).** Ни один результат не получает статус `attested` и не входит в диссертацию, пока к нему не выпущен понятный русскоязычный конспект со схемой в `research/guides/` и учебный пакет для **LearnHarness v0.7.0**.
6. **Единственная научная власть — человек.** Статус `attested` (допуск в диссертацию) ставит только владелец.

## 3. Лестница научных статусов

`intake` → `conjectured` → `survived-falsifier` *(только численно/символьно!)* → `formalized` *(Lean 4 / dual-route + G3)* → `verified` *(+ G4 Independent Math Review)* → `ready-for-attestation` *(+ Guide & LearnHarness pack)* → **`attested`** *(только человек)*.

Терминали: `refuted` *(навсегда с минимальным контрпримером)* и `descoped(причина)`.

## 4. Операционная модель (Q4, Level 3)

- **Единый источник научной памяти:** Git (`research/`, `verification/`, `thesis/`).
- **Единая очередь задач:** локальная **Vercel Board (`$BOARD_API_URL`, канал `autoresearcher`)**. Вторые трекеры (включая старые Beads) не используются.
- **Исполнение (Darkfactory, Level 3):** 1 worktree на самостоятельный тикет → сдача строго точным `candidate_sha` → доверенный локальный гейт → независимый ревьюер `board-review.mjs` на том же SHA. Автоматический возврат исправимого дефекта воркеру; владельцу выносится 1 чёткий вопрос только при реальной научной развилке или на аттестацию.
- **Git консервативно:** коммит/пуш только по явному указанию.
