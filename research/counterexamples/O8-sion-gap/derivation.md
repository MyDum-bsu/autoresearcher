# Контрпример O8 (`ce-o8-sion-gap`): строгий зазор порядка квантификаторов $V(R) > V_{\mathrm{mm}}$

> Статус: `falsified` (опровергнута узкая наивная гипотеза `hyp-o8-1d-sion-zero-gap` об обращении в нуль зазора порядка квантификаторов на одномерных системах `BridgeFormalV2.Data` по аналогии с теоремой Сиона; общая задача `conj-o8-quantifier-gap` об оценках зазора и точных условиях его исчезновения остаётся открытой).
> Верификатор (точные дроби `Fraction` + символьный сертификат непрерывного бокса SymPy, `-B` и `-B -O`): [checks/check_o8_gap.py](checks/check_o8_gap.py).

## 1. Опровергаемая гипотеза (`hyp-o8-1d-sion-zero-gap`)

Наивная гипотеза утверждала, что для любой допустимой одномерной системы `BridgeFormalV2.Data` с одним замыканием ($n=m=p=\text{rows}=r=q=1$) и компактными выпуклыми боксами $U = [-1, 1]$, $W = [-1, 1]$ выполняется равенство значений:
$$V(\{1\}) = V_{\mathrm{mm}}^{\mathrm{prefix}} = V_{\mathrm{mm}}^{\mathrm{full}},$$
то есть зазор порядка квантификаторов $\inf\sup - \sup\inf$ обращается в нуль.

## 2. Минимальный 1D-свидетель

Рассмотрим линейную дискретную систему на горизонте $T = r + q = 2$ ($r = 1, q = 1$):
$$A = 2,\quad B = 1,\quad E = 1,\quad x_0 = 0,\quad U = [-1, 1],\quad \rho = 1,$$
$$H = 1,\quad g_{\min} = -2,\quad g_{\max} = 4,\quad c = 1.$$

Терминальное состояние и терминальное ограничение имеют вид:
$$x_2 = 2 a + b + 2 w_0 + w_1 \in [-2, 4], \qquad a, b \in [-1, 1],\quad w_0, w_1 \in [-1, 1].$$

## 3. Точная иерархия значений на непрерывных боксах $w_0, w_1 \in [-1, 1]$

| Постановка | Формула с учётом терминального ограничения $-2 \le x_2 \le 4$ | Точное значение |
|---|---|---|
| Программное управление $V(\varnothing)$ | $\min_{a,b \in [-1,1]} \{\max_{w \in [-1,1]^2} x_2 \mid \forall w \in [-1,1]^2,\; -2 \le x_2 \le 4\}$ | **`4`** |
| Причинная ARO с одним замыканием $V(\{1\})$ | $\min_{a, b(\cdot)} \{\sup_{w \in [-1,1]^2} x_2 \mid \forall w,\; -2 \le x_2 \le 4\}$ (по теоремам F3 и F4 точно сводится к вершинам $w_0 \in \{-1, +1\}$ с сужением $\rho = 1$) | **`2`** (при $a = 0, b(-1) = 1, b(+1) = -1$) |
| Префиксный максимин $V_{\mathrm{mm}}^{\mathrm{prefix}}$ | $\sup_{w_0 \in [-1,1]} \min_{a,b \in [-1,1]} \{\max_{w_1 \in [-1,1]} x_2 \mid \forall w_1 \in [-1,1],\; -2 \le x_2 \le 4\}$ | **`0`** |
| Полный максимин $V_{\mathrm{mm}}^{\mathrm{full}}$ | $\sup_{(w_0,w_1) \in [-1,1]^2} \min_{a,b \in [-1,1]} \{x_2 \mid -2 \le x_2 \le 4\}$ | **`0`** |

### Обоснование перехода к непрерывным боксам (сертифицировано в `check_o8_gap.py`)

1. **$V(\varnothing) = 4$ и $V(\{1\}) = 2$:** для линейного функционала $2w_0 + w_1$ на непрерывном боксе $[-1, 1]^2$ экстремумы $\pm 3$ достигаются точно в углах; для $V(\{1\})$ по теоремам F3 и F4 (`BridgeF4ExtremeLP.lean`) непрерывная задача на $w_0 \in [-1, 1]$ эквивалентна вершинной ЛП на $w_0 \in \{-1, +1\}$.
2. **$V_{\mathrm{mm}}^{\mathrm{prefix}} = 0$ на всём непрерывном отрезке $w_0 \in [-1, 1]$:**
   - Сужение по $w_1 \in [-1, 1]$ превращает $-2 \le x_2 \le 4$ в $-1 \le 2a + b + 2w_0 \le 3$, а целевую функцию — в $2a + b + 2w_0 + 1$.
   - Из нижнего ограничения $2a + b + 2w_0 \ge -1$ следует $2a + b + 2w_0 + 1 \ge 0$ для всех $w_0 \in [-1, 1]$ и всех допустимых $(a, b)$.
   - Свидетель $a(w_0) = -w_0 \in [-1, 1]$, $b(w_0) = -1 \in [-1, 1]$ допустим для **каждого** $w_0 \in [-1, 1]$ и даёт $2a(w_0) + b(w_0) + 2w_0 = -1 \in [-1, 3]$ и значение $0$ тождественно.
3. **$V_{\mathrm{mm}}^{\mathrm{full}} = 0$ на всём непрерывном квадрате $(w_0, w_1) \in [-1, 1]^2$:**
   - Так как $2a + b$ пробегает $[-3, 3]$ и $2w_0 + w_1 \in [-3, 3]$, минимальное допустимое значение $x_2$ равно $f_{\mathrm{full}}(w_0, w_1) = \max(-2,\, 2w_0 + w_1 - 3) = \max(-2,\, 2(w_0 - 1) + (w_1 - 1)) \le 0$ для всех $(w_0, w_1) \in [-1, 1]^2$.
   - В точке $(w_0, w_1) = (1, 1)$ достигается $f_{\mathrm{full}}(1, 1) = 0$ (при $a = -1, b = -1$).

Итого:
- ценность измерения $V(\varnothing) - V(\{1\}) = 4 - 2 = 2 > 0$;
- строгий зазор порядка квантификаторов:
  $$V(\{1\}) - V_{\mathrm{mm}}^{\mathrm{prefix}} = 2 > 0, \qquad V(\{1\}) - V_{\mathrm{mm}}^{\mathrm{full}} = 2 > 0.$$

Дополнительно в [checks/check_o8_gap.py](checks/check_o8_gap.py) проверяется симметричный свидетель ($A = B = E = 1$, $g_{\min} = -1$, $g_{\max} = 1$), дающий $V(\{1\}) = 1$ против $V_{\mathrm{mm}}^{\mathrm{full}} = 0$.

## 4. Почему теорема Сиона не применима

В причинной задаче первого этапа $a$ фиксируется **до** реализации $w_0$, а ограничение $x_2 \in [-2, 4]$ должно выполняться **одновременно** для всех $(w_0, w_1)$. В максиминной релаксации игрок управления выбирает $a = a(w_0)$ уже после раскрытия $w_0$, получая нефизическую предвосхищающую свободу. Таким образом, компактность и выпуклость $U$ и $W$ не обнуляют зазор обязательства $V(R) - V_{\mathrm{mm}}$.
