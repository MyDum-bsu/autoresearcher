## Ловушка 1. Подставить будущее возмущение в аргумент правила: $y(\xi, w^+)$

- **Ошибочное упрощение:** записать двухэтапную ARO-политику как функцию всей неопределённости $y(\xi, w^+)$ вместо $y(\xi)$.
- **Почему это фатально:** в момент $r$ контроллер знает только текущее состояние $x_r$ (а значит, $\xi = x_r - s_0(a)$), при этом будущий блок $w^+ \in W^q$ остаётся неизвестным. Запись $y(\xi, w^+)$ даёт второй стадии доступ к будущему, релаксируя задачу: оптимальная гарантированная стоимость **может строго снизиться** относительно исходной задачи ОГУ (хотя на вырожденных примерах инфимум может совпасть).
- **Контрольный тест:** [C6.lean](../../../verification/lean/Controls/final-review/C6.lean) и [C6Negative.lean](../../../verification/lean/Controls/final-review/C6Negative.lean) формально доказывают невозможность одной `StatePolicy`, выбирающей разные управления $+1$ и $-1$ для двух разных будущих шумов при одном измеренном состоянии. В [bridge-transfer-v1/check.py](../../claims/bridge-transfer-v1/check.py) контроль `future_information_semantic_error` принудительно отвергает политику, меняющую суффикс по будущему шуму.
- **Урок для Пакета 01:** в `Model.lean` сигнатура `DeviationPolicy` жёстко фиксирует тип `rule : D.Z → D.ControlBlock D.q` без аргумента `wp`; будущее $w^+$ стоит только под универсальным квантором $\forall w^+ \in W^q$.

## Ловушка 2. Коррелированные пути вместо независимых блоков $W^T$ (контрпримеры D1 и D2)

В модели A4 (физ. с. 4) допустимы **все** комбинации возмущений по времени: $w = (w^-, w^+) \in W^r \times W^q$. Если же ослабить эту посылку и допустить **коррелированное** конечное множество полных путей (где прошлый префикс $w^-$ ограничивает, какие суффиксы $w^+$ возможны дальше), политика по префиксу $w^-$ получает дополнительную предсказательную информацию о $w^+$ и **может** дать строго лучший оптимум, чем политика по состоянию $x_r$ (при нетривиальной корреляции такой разрыв может возникать, хотя даже при коррелированных путях один и тот же второй блок может оставаться оптимальным для всех префиксов), а достаточность попарной совместимости продолжений в общем случае рушится.

### Контрпример D1 (4 пути, 3 префикса, зазор $1/4$ против $2$)
- **Опора:** [D1 derivation.md](../../counterexamples/D1-baseline/derivation.md), проверяемый скрипт [check_candidate_v2.py](../../counterexamples/D1-baseline/checks/check_candidate_v2.py).
- **Конструкция:** $T = 2, r = 1, n = m = 2$, $x_1 = (0, 0)$ на всех путях ($E_0 = 0$), $x_2 = b + w_1$, $b = (u, v) \in [0, 2]^2$, жёсткое терминальное условие $x_2 \ge 0$, знаковая стоимость $x_{2,1} + x_{2,2} \le q$. Четыре полных пути:
  - $A$: $w_0 = (0,0), w_1 = (0,0)$ (префикс $p_0$);
  - $B$: $w_0 = (1,0), w_1 = (-1,0)$ (префикс $p_1$);
  - $C$: $w_0 = (1,0), w_1 = (-1,-1/4)$ (тот же префикс $p_1$, скрытый суффикс!);
  - $D$: $w_0 = (0,1), w_1 = (0,-1)$ (префикс $p_2$).
- **Что происходит:** все три префикса склеиваются в одно измеренное состояние $x_1 = (0, 0)$. При уровне $q = 3/2$ **любая пара** префиксов имеет общее управление, но для всех трёх сразу требуются одновременно $u \ge 1$, $v \ge 1$ и $u + v \le 3/2$. Сложение неравенств даёт противоречие $0 \le -1/2$. Точные оптимумы: **политика по префиксу даёт $1/4$, политика по состоянию — $2$**.

### Контрпример D2 (3 пути, треугольная обструкция)
- **Опора:** [D2 derivation.md](../../counterexamples/D2-structured/derivation.md), скрипты [certificate_check_v2.py](../../counterexamples/D2-structured/checks/certificate_check_v2.py) и [trajectory_check_v2.py](../../counterexamples/D2-structured/checks/trajectory_check_v2.py).
- **Конструкция:** та же геометрия $x_1 = (0,0)$, $x_2 = b + w_1$, $b = (x, y) \in [0, 2]^2$, три пути: $p_1: w_1 = (-1,0)$, $p_2: w_1 = (0,-1)$, $p_3: w_1 = (0,0)$.
- **Что происходит:** при $q = 1$ множества допустимых продолжений $K_1(1), K_2(1), K_3(1)$ — сдвиги одного треугольника; каждая пара пересекается (свидетели $(1,1)$, $(1,0)$, $(0,1)$), но сложение трёх ограничений даёт $0 \le -1$. При $q = 2$ общее управление существует, хотя остаточные характеристики префиксов различны — это опровергает необходимость равенства характеристик для совместимости на фиксированном уровне $q$.

- **Урок для Пакета 01:** D1 и D2 демонстрируют именно возможный разрыв между политикой по префиксу $w^-$ и политикой по состоянию $x_r$ при коррелированных путях (а также крах достаточности попарной совместимости). Сам аддитивный сдвиг $x_r = s_0(a) + \xi$ остаётся корректным при точном переносе совместного множества путей; декартова структура $W^T = W^r \times W^q$ в `Model.lean` гарантирует одинаковое множество будущих суффиксов $w^+$ для всех префиксов с одним $x_r$ и исключает потерю предсказательной информации.

## Ловушка 3. Неаккуратная формулировка «ранг $\le 1 \iff$ попарная совместимость» (E и Astra A-S1)

После D2 возник естественный вопрос: если матрица общих остаточных ограничений имеет ранг $\le 1$, достаточно ли попарной совместимости? Проверка выявила сразу две тонкие границы:

1. **Пропущенный случай синглтона (`E-rank1`):** если понимать «попарную совместимость» как условие на *различные* пары $i \neq j$, то ячейка из одного префикса удовлетворяет этому условию пустым образом — даже когда само множество $K_p$ пусто! В [E handoff.md](../../counterexamples/E-rank1/handoff.md) и [rank_one_check.py](../../counterexamples/E-rank1/checks/rank_one_check.py) построены точные синглтон-контрпримеры при ранге $0$ и $1$ и сформулировано исправленное утверждение (`E-R1-child-v1`): непустота каждого $K_p$ **плюс** попарная совместимость.
2. **Ранг $\le 1$ не необходим (`Astra A-S1`):** в [Astra A-S1 handoff.md](../../counterexamples/astra-probe-AS1/handoff.md) и письменном выводе [derivation.md](../../counterexamples/astra-probe-AS1/derivation.md) (статус `unproved-sketch`, без Lean-формализации) описан подкласс `A-S1` с матрицей **ранга 2**, где каждая ненулевая строка зависит лишь от одной координаты управления (без смешанной диагонали $e_1 + e_2$ из треугольника D2) и все префиксы делят **общий координатный бокс управлений** (без повёрнутых боксов). Письменное доказательство по концам интервалов показывает, что для любого конечного семейства из `A-S1` индивидуальная непустота плюс попарная совместимость влекут совместное продолжение; отдельно скрипт [check.py](../../counterexamples/astra-probe-AS1/checks/check.py) выполняет 38 точных рациональных проверок на конкретном четырёхпутевом примере и контрольных кейсах (эти тесты проверяют экземпляр и не заменяют формальную верификацию общего утверждения).

- **Урок для фабрики:** именно так работает принцип *Falsify-First* — каждая гипотеза сначала уточняется минимальными контрпримерами, а опровергнутый родитель сохраняется рядом с уточнённым потомком.

## Ловушка 4. Путать игрушечный класс старого глоссария с общей моделью A4

В раннем этапе проекта (`v1`) под «мост-классом» понимали узкую 2D-игрушку. Пакет 01 работает строго с **общей моделью A3/A4**:

| Ось | Узкий класс v1 (старый глоссарий) | Общая модель Пакета 01 (`BridgeFormalV2` / A4) |
|---|---|---|
| Динамика | $A = I, B = (1,1)^\top$, $x_0 = (d_0, d_0)$ | Произвольные линейные $A, B, E$ (без обратимости $A$ и без $B = E$) |
| Возмущения | Дискретные вершины $\{-1, +1\}^T$ | Непрерывный куб $W^T = [-\rho, \rho]^{pT}$, $\rho > 0$ |
| Цель и ограничения | Терминальная норма $\|x_T\|_1$ | Жёсткая полоса $\underline h \le H x_T \le \overline h$ и знаковый линейный критерий $c^\top x_T$ |
| Информация | Ключ LP содержал весь префикс $w^-$ | Только точное текущее состояние $x_r$ (или эквивалентное $\xi = x_r - s_0(a)$) |
