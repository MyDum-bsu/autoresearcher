# Контур понимания владельца (`research/guides/`)

> **Правило «No Black-Box Theorems» (`CHARTER.md §2.5`):** ни один математический результат не получает статус `attested` и не входит в диссертацию, пока к нему не выпущен понятный русскоязычный 4-файловый конспект в `research/guides/<topic-id>/`, прошедший гейт **G5** (`make verify-guides`).

## Стандарт 4-файлового учебного пакета

Каждый пакет в `research/guides/<NN-slug>/` обязан содержать ровно четыре файла (шаблон — в [TEMPLATE/](TEMPLATE/01-intuition-and-map.md)):

| Файл | Назначение | Зачем нужен в LearnHarness v0.7.0 |
|---|---|---|
| `01-intuition-and-map.md` | Картина за 10 минут: зачем нужен результат, геометрическая/физическая интуиция, **Mermaid-схемы**, таблица «Доказано / НЕ доказано» | Даёт контекст для Teach-сессии (`Prober → Plan → Teacher`) |
| `02-propositions-and-chains.md` | Атомарные определения, предпосылки и явные **совместные цепочки** (`P1 + P2 ⇒ C`) со ссылками на Lean-декларации и физические страницы PDF | Оптимизирован под экстрактор `POST /api/graph/import` (`nodes.jsonl` + `chains.jsonl`) без потери кванторов |
| `03-traps-and-counterexamples.md` | Минимальные контрпримеры и ловушки (что ломается при ослаблении каждой предпосылки) | База для FSRS Flashcards и Practice-проверок границ |
| `04-practice-and-attestation.md` | 3–5 градуированных мини-задач для закрепления + чек-лист развилок для владельца и научрука | Практическая проверка «щелчка» понимания перед ручным статусом `attested` |

## Проверка гейтом G5

```bash
make verify-guides
```

Гейт [verify_guides.py](../../verification/gates/verify_guides.py) проверяет:
1. Наличие всех 4 файлов в каждом активном пакете (`research/guides/<NN-slug>/`, кроме `TEMPLATE/` и `00-source-packet-01/`).
2. **Anchor-lint:** 100% относительных Markdown-ссылок (включая reference-ссылки `[text][id]` + `[id]: path`, фрагменты `#anchor` заголовков и `#page=N` PDF) ведут на реальные файлы репозитория; каждая упомянутая статья `corpus/...` присутствует в `corpus/MANIFEST.md` (или `corpus/extra/`); каждая упомянутая декларация `BridgeFormalV2.Proofs.*` есть в `expected-theorems-v2.json` и Lean-файлах.
3. **LaTeX-синтаксис:** порядок и парность `$$`, `$`, `\[`/`\]`, `\(`/`\)`, фигурных скобок и `\begin{...}`/`\end{...}` вне блоков кода.
4. **Mermaid-синтаксис:** наличие минимум одной схемы в `01-intuition-and-map.md`, допустимый тип диаграммы, отсутствие HTML-тегов в подписях, парность кавычек/скобок и отсутствие висячих стрелок.
5. **Стиль (`technical-style-editor`, RU):** прогон `lint_technical_style.py --language ru` без замечаний.
