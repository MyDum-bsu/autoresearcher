# O4 / O7 (часть 2): Ловушки, контрпримеры и честная граница открытого

1. **Ловушка знака дефекта субмодулярности:**
   - В `run02_falsify.py` дефект определяется как $\Delta = (G(\{1,2\}) - G(\{1\})) - (G(\{2\}) - G(\emptyset))$.
   - Отрицательный дефект ($\Delta = -1 < 0$) означает **строгую субмодулярность** (убывающую отдачу), а не её нарушение!
   - Истинное **опровержение субмодулярности** требует $\Delta > 0$ (супермодулярной синергии). На 1D-системах с одним терминальным ограничением супермодулярность в широкой сетке не возникла, но на 4D сдвиговом регистре `synergyWitnessData` с двумя связанными каналами $|u_1 + w_0| \le u_0$ и $|u_2 + w_1| \le u_0$ она проявляется в чистом виде ($\Delta = +1$).
2. **Ловушка «жадный выбор замыканий гарантирует $(1 - 1/e)$ оптимума»:**
   - Из теоремы `exists_strict_supermodular_synergy` следует, что в общем классе линейных стационарных систем с боксовыми возмущениями жадный выбор первого замыкания видит нулевой выигрыш для любого одиночного момента ($G(\{1\}) = G(\{2\}) = 0$), тогда как пара $\{1, 2\}$ даёт полный выигрыш $1$.
3. **Ловушка «раньше измерить всегда лучше» или «позже измерить всегда лучше» (`O7`):**
   - При ограниченном авторитете управления ($U = [-1/2, 1/2]$, $A = 1$) раннее замыкание $r = 1$ выигрывает за счёт двух шагов коррекции ($u_1, u_2$) против одного ($V(\{1\}) = 2 < 3 = V(\{2\})$).
   - При затухающей динамике ($A = 1/2$) и достаточном авторитете ($U = [-1, 1]$) позднее замыкание $r = 2$ выигрывает за счёт наблюдения обоих возмущений $w_0, w_1$ ($V(\{2\}) = 0 < 1 = V(\{1\})$).
4. **Честная граница частичного покрытия `O4 + O7`:**
   - Полностью доказаны решётка монотонности на $T = 3$, схлопывание при `D.rows = 0`, не-субмодулярность и не-супермодулярность $G(R)$, а также двустороннее доминирование одиночных замыканий.
   - **Открытыми остаются:** достаточные структурные условия субмодулярности $G(R)$ (например, проверка гипотезы о субмодулярности для 1D-систем с одним односторонним терминальным ограничением) и алгоритмическая характеризация оптимального расписания $R^*$ при фиксированном бюджете $|R| \le k$.
