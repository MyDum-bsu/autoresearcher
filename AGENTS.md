# aro-discovery v2 — правила агентов

> Устав проекта: `CHARTER.md` (утверждён владельцем 2026-11-23).
> При любом конфликте приоритет имеет `CHARTER.md`.

## Язык
- Формальный пайплайн, код, идентификаторы, Lean 4, артефакты судей и схемы — строго на английском.
- Документы диссертации (`thesis/`), учебные конспекты (`research/guides/`), `CHARTER.md`, `README.md`, отчёты и общение с владельцем — на русском.

## Железные правила
1. **Очередь задач — только локальная Vercel Board (`$BOARD_API_URL`, канал `autoresearcher`).** Beads и самодельные TODO-трекеры не используются.
2. **Единая научная память — Git (`research/`, `verification/`, `thesis/`).** Никаких SQLite-проекций и монолитных журналов поверх Git.
3. **Внешняя опора** = физическая страница PDF из `corpus/` (с SHA-256) или детерминированный артефакт судьи. По памяти — никогда.
4. **LLM не судит.** Вердикты выдают код-судьи (`verification/`) и Lean 4; автор не принимает свою работу (обязателен независимый ревьюер `board-review.mjs`).
5. **Falsify-First:** сначала точный LP / SymPy / батарея `T1–T7` (Stage 2), только потом Proof Synthesis и Lean 4 (Stage 3). Опровергнутые гипотезы не переписываются — сохраняются в `research/counterexamples/`.
6. **Замороженные цели Lean:** при работе над доказательством запрещено ослаблять `Goals.lean` / `Model.lean`.
7. **No Black-Box Theorems:** каждый закрытый научный результат обязан иметь понятный русский конспект в `research/guides/` для импорта в LearnHarness v0.7.0. Статус `attested` ставит только человек.
8. **Git консервативно:** коммит/пуш/PR — только по явному указанию.
9. **Прокси-среда:** по умолчанию не трогать.
